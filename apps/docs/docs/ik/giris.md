# İK rehberine hoş geldiniz

UpCore İK rehberi 8 modül üzerine kuruludur. Her modül, günlük operasyonunuzdan stratejik planlamaya kadar ayrı bir yetenek sunar.

## 8 modül özeti

| Modül | Amaç | En çok kullanılan özellik |
|---|---|---|
| 🟢 [Sürdürme](/docs/ik/modul/surdurme/genel-bakis) | Pulse + heatmap ile bağlılık izleme | Pulse kurulumu |
| 🛡️ [Koruma](/docs/ik/modul/koruma/genel-bakis) | Tükenmişlik önleyici müdahale | Thompson sampling öneri |
| 🎯 [Performans](/docs/ik/modul/performans/genel-bakis) | OKR + 360 + 9-kutu | Yıl sonu değerlendirme |
| 🚀 [Mobility](/docs/ik/modul/mobility/genel-bakis) | İç ilan + succession | Succession pool |
| 📚 [Geliştirme](/docs/ik/modul/gelistirme/genel-bakis) | Yetkinlik + öğrenme yolu | Sertifika takibi |
| ⚙️ [İK Ops](/docs/ik/modul/ik-ops/genel-bakis) | Bordro, izin, SGK | SGK e-Bildirge |
| 📊 [Analitik](/docs/ik/modul/analitik/genel-bakis) | Executive dashboard | Yıllık rapor |
| 🛡️ [KVKK/GRC](/docs/ik/modul/kvkk/genel-bakis) | Madde 11 + VERBIS + DPIA | İhlal bildirim 72s |

## Hızlı başlangıç

İlk hafta yapmanız gerekenler:

1. [İlk 15 dakika](/docs/ik/hizli-baslangic/ilk-15-dakika) — organizasyon tanımı
2. [İlk pulse anketi](/docs/ik/hizli-baslangic/ilk-pulse-anketi) — BAT-TR ile başlangıç
3. [İlk müdahale](/docs/ik/hizli-baslangic/ilk-mudahale) — kırmızı band → Thompson → plan
4. [Yıl sonu değerlendirme](/docs/ik/hizli-baslangic/yil-sonu-degerlendirme) — 360 + OKR + 9-kutu
