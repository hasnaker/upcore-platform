# Sürdürme modülü — genel bakış

Sürdürme modülü UpCore'un **erken uyarı sistemidir**. Pulse anketleri ile çalışan bağlılığı ve tükenmişlik sinyallerini izler.

## Bilimsel temel

- **JD-R modeli** (Demerouti & Bakker, 2001): İş talepleri ↑ + kaynaklar ↓ → tükenmişlik
- **BAT-TR** (Koçak, 2022): Türkiye normuna sahip 12/23 madde tükenmişlik ölçeği
- **UWES-9** (Schaufeli et al., 2006): İş bağlılığı ölçeği
- **COPSOQ-III-TR** (Şahan, 2019): Psikososyal iş ortamı değerlendirme

## Modül bileşenleri

| Bileşen | Açıklama |
|---|---|
| Pulse oluşturucu | Şablon + özel soru + cadence |
| Heatmap | Departman × madde matrisi |
| Trend analiz | Zaman serisi, mevsimsel düzeltme |
| Bant sınıflandırma | Yeşil / sarı / kırmızı |
| JD-R dashboard'u | Talep/kaynak dengesi |
| Soru bankası | 250+ bilimsel madde |
| Raporlama | PDF, Excel, JSON export |

## Kullanım ritmi

- **Haftalık:** İK 1 saat sonuç inceleme
- **İki haftada bir:** Pulse gönderim
- **Aylık:** Yönetici toplantısında özet
- **Çeyrek:** Board-level rapor
