# JD-R boyut yorumu

**JD-R modeli** (Job Demands–Resources, Demerouti & Bakker 2001) çalışan refahını iki eksende değerlendirir.

## İki ana eksen

### İş talepleri (Job Demands)

Enerji tüketen fiziksel, psikolojik, sosyal, örgütsel işletim özellikleri.

| Alt boyut | Örnek madde |
|---|---|
| İş yükü | "Yaptığım işi tamamlamak için yeterli zamanım var" (ters) |
| Zaman baskısı | "Çalışırken aceleyle iş yapma zorunluluğu hissederim" |
| Duygusal talep | "İşim duygusal olarak yıpratıcıdır" |
| Rol belirsizliği | "Rolümün sınırları net değil" |
| Rol çatışması | "Birden fazla yönetici bana çelişkili talimatlar verir" |

### İş kaynakları (Job Resources)

Enerji sağlayan / talep etkisini yumuşatan faktörler.

| Alt boyut | Örnek madde |
|---|---|
| Özerklik | "İşimi nasıl yapacağıma kendim karar veririm" |
| Geri bildirim | "Yöneticim performansım hakkında düzenli geri bildirim verir" |
| Sosyal destek | "Takım arkadaşlarımdan ihtiyaç duyduğumda destek alabilirim" |
| Gelişim fırsatı | "İşimde yeni şeyler öğrenme imkanım var" |
| Tanıma | "Gösterdiğim çabalar takdir edilir" |

## İki süreç

1. **Sağlık kaybı süreci:** Talepler ↑ → tükenmişlik → fiziksel/mental sağlık ↓
2. **Motivasyon süreci:** Kaynaklar ↑ → bağlılık → performans ↑

## UpCore'da JD-R panosu

Her departman için şu görsel üretilir:

```
Kaynaklar eksenindeki yüksek →
                              Star:
                              İdeal — yüksek talep, yüksek kaynak
                              yüksek bağlılık + yönetilebilir tükenmişlik

Talepler ekseninde düşük ←    Comfort zone:
                              Düşük stres ama motivasyon düşük olabilir

                              Burnout zone:
                              Yüksek talep, düşük kaynak
                              Acil aksiyon gerekli

                              Bore-out zone:
                              Düşük talep, düşük kaynak
                              Motivasyon ve iş zenginleştirme gerekli
```

## Müdahale mantığı

| Durum | Öncelik |
|---|---|
| Talepler yüksek, kaynaklar yüksek | İzleme — stres yönetimi atölyesi |
| Talepler yüksek, kaynaklar düşük | **Acil müdahale** — iş yükü azalt + kaynak ekle |
| Talepler düşük, kaynaklar yüksek | Rol zenginleştirme |
| Talepler düşük, kaynaklar düşük | Kariyer yolu + mobility |

## Bilimsel referans

> Demerouti, E., Bakker, A. B., Nachreiner, F., & Schaufeli, W. B. (2001). The job demands-resources model of burnout. *Journal of Applied Psychology, 86*(3), 499-512.
