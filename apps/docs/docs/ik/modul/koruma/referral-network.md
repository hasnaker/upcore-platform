# Referral network (anonim profesyonel ağ)

Bazı vakalar iç kaynaklarla çözülemez — lisanslı uzmanlara **anonim yönlendirme** gerekir.

## Ağ üyeleri

UpCore ile kontratlı uzmanlar:

| Rol | Lisans / kalifikasyon | Tipik ücret (UpCore sübvansiyon sonrası) |
|---|---|---|
| Klinik psikolog | TPD üyesi, 3+ yıl | 1500 TL/seans — %70 işveren katkı |
| Psikiyatrist | Tabipler Odası kayıtlı | 2000 TL/seans |
| Yaşam koçu | ICF onaylı | 1200 TL/seans |
| Kariyer danışmanı | ICF + HR Lisans | 1000 TL/seans |
| Mali danışman (EAP kapsamında) | SPK lisanslı | 800 TL/seans |
| Hukuk danışmanı (EAP) | Baroya kayıtlı | 1500 TL/30 dk |

## Nasıl çalışır?

1. İK "referral öner" butonuna basar
2. Çalışana anonim açık rıza formu gider
3. Çalışan kabul ederse → anonim kod atanır (`REF-2026-0001`)
4. Uzman listesi görünür (3 seçenek)
5. Çalışan kendi seçer, kendi randevu alır
6. UpCore seçim/randevu detaylarını **görmez**
7. İşveren **aylık toplam seans sayısı**ni görür (faturalandırma için)

## Anonimlik sınırları

- UpCore: çalışan kimliği ↔ anonim kod eşleştirmesini tutar (KVKK uyumlu veri işleyen)
- Uzman: sadece anonim kodu görür — çalışanın gerçek adını asla
- Fatura: toplu kurumsal fatura, bireysel kullanım yazmaz

## Klinik eskalasyon kriterleri

Sıradan koçluk yerine psikolog/psikiyatr referansı önerilir:
- İntihar düşüncesi / kendine zarar verme işareti
- Panik atak tekrarlayan
- Ciddi depresyon şüphesi (PHQ-9 ≥ 15)
- Anksiyete bozukluğu (GAD-7 ≥ 15)
- Alkol/madde bağımlılığı
- İş kazası sonrası travma belirtisi

:::danger Kriz
İntihar riskini **asla** yönetmeye çalışmayın. Derhal:
- 182 (Hayat Hattı)
- 112 (acil tıbbi destek)
- UpCore acil psikolog hatti: **0850 252 8726** (24/7)
:::

## Faturalandırma

- Aylık fatura kullanılan seans sayısı × sözleşme fiyatı
- Enterprise plan: aylık 20 seansa kadar dahil
- Başına % veya toplam bütçe yerel yönetim tarafında ayarlanır
