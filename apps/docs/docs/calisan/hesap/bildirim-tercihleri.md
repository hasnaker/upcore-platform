# Bildirim tercihleri

UpCore, hangi olaylarda hangi kanaldan haberdar edileceğinizi tamamen sizin kontrolünüze bırakır.

## Olay → kanal matrisi

| Olay | Öneri | Kapatılabilir mi? |
|---|---|---|
| Pulse daveti | E-posta + Slack | Hayır (KVKK aydınlatma) |
| 360 değerlendirme daveti | E-posta + in-app | Hayır |
| 1-1 görüşme hatırlatıcısı | Slack / Teams | Evet |
| Yeni iç ilan (kariyer tercihi eşleşmesi) | E-posta | Evet |
| Öğrenme yolu ilerleme | in-app | Evet |
| Sistem bakımı (planlı) | E-posta | Evet |

## Sessiz saatler

- Varsayılan: **22:00 – 08:00** (şirket saat dilimi)
- Hafta sonu tamamen sessiz seçeneği mevcut
- Acil güvenlik olayları (örneğin kimlik doğrulama saldırısı) sessiz saatleri bypass eder

## Toplu kapatma

**İletişim tercihleri > Tümünü kapat** seçeneği 30 günlük geçici bir moddur (örn. yıllık izin). 30 gün sonra otomatik önceki ayarlara döner.
