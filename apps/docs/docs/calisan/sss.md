# Sıkça sorulanlar

## Yöneticim pulse cevaplarımı görüyor mu?

**Hayır.** Yöneticiniz yalnızca departman agregasını (en az 5 kişi) görür. Bireysel cevaplar tasarım gereği ulaşılmaz.

## Cevap verme zorunluluğum var mı?

Hayır. Pulse'a cevap vermemek **performansınıza** veya **özlük dosyanıza** yansımaz. Ancak cevap vermezseniz İK'nın size uygun müdahale önerisi üretme kapasitesi azalır.

## ChatGPT, verilerim ile eğitim mi yapıyor?

Hayır. UpCore'un ML modelleri **kendi sunucularında** çalışır; 3. taraf LLM şirketlerine (OpenAI, Anthropic, Google) kişisel veri gönderilmez. Tek istisna: açık rızanız varsa serbest metin yorumlarınızın anonimleştirilmiş versiyonu duygu analizi için model eğitiminde kullanılabilir.

## Sistem kapalı mı?

[status.upcore.io](https://status.upcore.io) üzerinden canlı durum sayfasını kontrol edin.

## Ücretsiz mi?

Çalışan tarafı tamamen ücretsizdir — faturalandırma şirketinize yapılır. Kendi İK sisteminizde hesap ücreti ödemezsiniz.
