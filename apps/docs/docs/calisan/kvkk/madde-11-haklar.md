# KVKK Madde 11 hakları

6698 sayılı Kişisel Verilerin Korunması Kanunu'nun 11. maddesi size şu hakları tanır:

| Fıkra | Hak | UpCore'da nasıl |
|---|---|---|
| (a) | Kişisel verinizin işlenip işlenmediğini öğrenme | Hesap > KVKK > Verilerim |
| (b) | İşlenmişse bilgi talep etme | "Veri envanteri raporu" indirme |
| (c) | İşleme amacını ve amaca uygun kullanıldığını öğrenme | Aydınlatma metni |
| (ç) | Yurt içi/yurt dışı aktarım öğrenme | Alt işleyici listesi |
| (d) | Eksik/yanlış işlenmişse düzeltme | Profil > Düzeltme talebi |
| (e) | Silme veya yok edilmesini isteme | KVKK > Silme talebi |
| (f) | (d) ve (e) bentleri kapsamındaki düzeltme/silmenin aktarıldığı 3. taraflara bildirim | Otomatik |
| (g) | Otomatik sistemlerle analiz sonucu aleyhe sonuç çıkması durumunda itiraz | ML kararlarına itiraz formu |
| (ğ) | Kanuna aykırı işleme ile zarar → tazminat talep etme | Hukuki yol |

## Ne kadar sürede cevap alırım?

- **30 gün** içinde (Madde 13/2)
- Karmaşık talepler için **60 güne kadar uzatma** olabilir — size yazılı bilgi gelir
- Red durumunda **gerekçe yazılı** olarak bildirilir

## Portale erişim

Hesap menüsü > **KVKK Haklarım** sayfası tüm talepleri self-servis oluşturmanıza izin verir.

Alternatifler:
- E-posta: `kvkk@upcore.io`
- KEP: `upcore@hs01.kep.tr`
- Posta: Noter kanalıyla yazılı başvuru

## Ücret

- Madde 13/2'ye göre **ücretsiz** (10 sayfayı geçen çoğaltma ücreti uygulanabilir — KVK Kurulu kararı)
