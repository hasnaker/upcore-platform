# Müdahale onayı

İK bir müdahale planı önerdiğinde, yönetici olarak rolünüz sınırlıdır ama kritiktir.

## Sorumluluk bölümü

| Taraf | Sorumluluk |
|---|---|
| İK | Müdahale türü seçimi (Thompson sampling + klinik judgement) |
| Yönetici | Süreç desteği (zaman tanıma, pozitif iklim) |
| Çalışan | Açık rıza + müdahaleye katılım |
| Psikolog (opsiyonel) | 1-1 terapi seansları (yasal çerçeve içinde) |

## Onaylanacak bölüm

Size gelen onay ekranında şunları göreceksiniz:
- Müdahale adı (ama **çalışan adı değil** — İK bilir)
- Tahmini süre (örneğin 8 hafta)
- Çalışma saatlerinden harcanacak süre (haftada ~2 saat)
- Bütçe etkisi (varsa)

Onaylar yalnızca **çalışma saati** ve **bütçe** boyutlarındadır. Müdahalenin içeriği gizli kalır.

## Tavsiye

- Müdahale başlayan çalışana **açıkça** "bu süreçte sana destek olacağım" deyin
- Süreç sırasında **iş yükünü azaltmak** en güçlü etkili yardımdır (haftada 2 saat azaltma → Cohen's d ~ 0.4)
- Süreç sonu skor iyileşmezse **suçlama sırası size gelmez** — İK alternatif plan üretir
