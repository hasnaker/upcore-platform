# OKR belirleme

OKR = **Objective** (nereye gidiyoruz?) + **Key Result** (nereye vardığımızı nasıl ölçeriz?).

## İyi OKR kriterleri (SMART+)

- **Specific:** Net — "geliri artır" değil, "B2B MRR'yi 5M TRY'ye çıkar"
- **Measurable:** Sayısal — duygu değil rakam
- **Ambitious:** %70–80 hedefe ulaşma normal. %100 → çok kolay koymuşsunuz
- **Realistic:** Kaynak/zaman içinde mümkün olmalı
- **Time-bound:** Çeyrek (Q1, Q2...)

## Objective örneği
> "B2B satışlarını ikiye katlayalım ve müşteri memnuniyetini koruyalım."

**Key Results (3–5):**
1. MRR 2.5M → 5M TRY (Q2 sonu)
2. Yeni kazanılan müşteri sayısı ≥ 30 (Q2)
3. NPS ≥ 50 (aylık ölçüm)
4. Kritik bug kapatma süresi ≤ 24 saat

## Kaskad (cascade)

- Şirket OKR → Departman OKR → Ekip OKR → Çalışan OKR
- Her seviyede 1 Objective'a **en fazla 4 KR** öneriyoruz
- Alt seviye OKR'ları üst seviyeye **bağlı** olmalı (sistem zorlar)

## Güncelleme ritmi

- Haftalık: KR ilerleme yüzdesi (çalışan kendi günceller)
- İki haftada bir: yönetici kontrolü
- Çeyrek sonunda: öz değerlendirme + yönetici değerlendirme + kalibrasyon

:::info
OKR yüzdesi **terfi/zam kararında** tek başına kullanılmaz. Kanıt setinde bir girdi olur.
:::
