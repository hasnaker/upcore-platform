UpCore v2 beta sürümü bugün itibariyle tüm Enterprise müşterilere açıldı. v2 ile gelen en önemli değişiklikler:

<!-- truncate -->

## Yenilikler

### Mobility modülü tamamen yenilendi
- İç ilan marketplace
- Succession pipeline (ready-now sınıflandırma)
- Kariyer yolu drag-and-drop editörü
- 9-kutu ile otomatik entegrasyon
- Ayrılış risk tahmini ML modeli

### ML modelleri v3
- Burnout prediction doğruluğu %72 → %78
- Intervention recommendation Thompson sampling contextual bandit ile
- Fairness audit yıllık zorunlu

### API v2
- GraphQL (beta)
- Cursor-based pagination
- Idempotency key header zorunlu (ödeme endpoint'lerinde)
- Rate limit %50 artırıldı

### KVKK/GRC geliştirmeleri
- Madde 11 self-servis portal tamamen yeni
- VERBIS asistan
- DPIA şablonu 3 kategori için
- İhlal bildirim 72 saat SLA otomasyonu

## Breaking changes

- `/api/v1/surveys` endpoint `pulses` olarak rename edildi (v1 → 12 ay grace period)
- `employee.manager_id` nullable → not null (manager atanması zorunlu)
- Webhook payload format değişti — `data` wrapper eklendi

## Migration rehberi

v1 → v2 geçiş için [migration guide'a bakın](/docs/developer/api/versiyonlama).
