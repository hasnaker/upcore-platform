# Human Resources Security Policy

**ID:** POL-09 · **Version:** 1.0 · **Effective:** 2026-04-23 · **Owner:** People Ops + CISO
**Review cadence:** annual · **Frameworks:** SOC 2 CC1.4, CC1.5 · ISO 27001 A.6.1–A.6.8 · KVKK md. 12

## 1. Purpose
Embed security into the employee lifecycle: pre-hire, hire, development, termination.

## 2. Pre-hire
- **Background check** on every hire (employment verification, criminal record for TR/EU, education for senior).
- Third-party provider (Sterling / HireRight) with DPA.
- Adverse findings reviewed by CISO + People Ops before offer.

## 3. On hire
- Signed NDA, IP assignment, code of conduct, acceptable use (POL-02).
- Security onboarding training within 7 days (POL-15).
- Role-specific training within 30 days (developers: secure coding + OWASP Top 10; support: PII handling).

## 4. Ongoing
- Annual refresher training — phishing sim, KVKK, incident recognition.
- Role change triggers access re-baseline (POL-01).
- Performance review includes security-objectives adherence.

## 5. Termination
- Revocation within 4 h (POL-01 §5.3).
- Exit interview includes data-handling acknowledgement and return of UpCore assets.
- Non-disclosure survives employment per contract.

## 6. Disciplinary process
Security violations follow progressive discipline: documented warning → final warning → termination. Willful misconduct → immediate termination + potential criminal referral (TCK md. 243, 244).

## 7. Contractors and interns
Same standards as employees, pro-rated training; time-boxed access (max contract duration + 30 days grace).

## 8. Audit and evidence
- HRIS records for background check, signatures, training completion.
- Quarterly JML audit report (access provisioned/revoked within SLA).
